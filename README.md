# 传播心理解码 Skill

> 用传播学与社会心理学理论解码内容的共鸣机制、受众情绪、有效立场和传播动机。

![version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## 这个 Skill 做什么

- 解码内容的主导共鸣机制（社会认同、情绪评价、框架理论、使用与满足、情绪激活与分享）
- 分析受众身份、问题框架、情绪评价和内容用途
- 区分观看、收藏、评论和分享的不同动机
- 指出受众在同一心理机制下还想听什么
- 给出后续内容的选题方向

## 5 个主理论

| 理论 | 解释什么 |
|---|---|
| 社会认同与自我分类 | 受众为什么觉得"这说的是我们" |
| 情绪评价理论 | 受众如何形成愤怒、焦虑、释然等具体情绪 |
| 框架理论 | 内容如何定义问题、归因和评价 |
| 使用与满足 | 受众为什么观看、收藏或持续关注 |
| 情绪激活与在线分享 | 什么驱动受众转发 |

另有 3 个条件理论（沉默的螺旋、认知失调、两级传播），满足触发条件才调用。

## 与 sansan-resonate 的区别

- `sansan-resonate`：诊断共鸣问题出在哪里（偏修复）
- `sansan-spread`：解码已经成立的传播机制并推导后续方向（偏延展）

## 使用方式

```
帮我分析这段内容为什么能引起共鸣：
[粘贴内容]
```

## 安装

```bash
npx skills add https://github.com/sansan19900801/sansan-spread --skill sansan-spread -g --copy
```
